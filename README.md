# Breast Cancer Prediction Project

## Overview
This project develops a machine learning model to predict 
whether a patient has breast cancer based on tumor features.

## Models Trained
- Logistic Regression
- Decision Tree
- Random Forest
- AdaBoost
- Support Vector Machine (SVC)
- Naive Bayes
- K-Nearest Neighbors

## Technologies Used
- Python, Flask, Scikit-learn
- Pandas, NumPy, Matplotlib

## How to Run
pip install -r requirements.txt
python app.py
